# Website typography

Unmodified Pretendard Variable is self-hosted for BooKoo's website, matching the
app's existing Pretendard family without a third-party font request. The complete
SIL OFL 1.1 notice is distributed next to the font in public/assets/fonts/OFL.txt.

Source: https://github.com/orioncactus/pretendard
Font: packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
License: LICENSE from the same repository, retrieved October24, 2026.
Japanese and Chinese glyphs use the reader's available local CJK sans-serif
fallback. This does not claim that all app capture languages are available.
