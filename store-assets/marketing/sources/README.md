# Marketing screenshot sources

These overrides are full-resolution BooKoo captures from the development
simulator data set. They are frozen separately from broad E2E inventories so
the marketing generator cannot accidentally regress to an empty or ambiguous
screen.

- Android timeline: populated day-grouped entries.
- Android statistics: Expense view with Transport, Education, Meal, and Cafe.
- iPhone, iPad, and Android ledgers: three realistic personal/shared ledgers.
- iPhone statistics: Expense view with multiple visible categories.
- iPhone, iPad, and Android appearance: dark theme active or selected.

The UI is not reconstructed or generated. Names and entries are synthetic
product-demo personas, never real user data. The abstract marketing background
is the only generated visual layer.
