2026-11-04

선택 국가별 활성 계정 통계를 추가했습니다. 기본 꺼짐과 철회, IP 추정 국가 코드만 보관하는 범위, Vercel 처리, 미상 및 추정 한계를 고지합니다. 이용약관 본문은 바꾸지 않았습니다.

2026-10-22

1.3.0 네이티브 업데이트의 Free 배너를 Unity LevelPlay/ironSource Ads·Unity Ads로 전환하고 Google UMP는 동의 관리에만 유지합니다. 처리 업체와 국외 처리, 비개인 맞춤형 광고 및 분석 제외 설정을 갱신했습니다. 이전 버전의 AdMob 동작은 업데이트 전까지 남을 수 있습니다. 이용약관 본문은 변경하지 않았습니다.

2026-10-14

구독 검증 처리자를 IAPKit(Hyo Dev)으로 전환했습니다. 앱 내부 식별자, 스토어 영수증·구매 토큰 및 구독 기록을 검증하며 가계부 내용과 결제 카드 정보는 전달하지 않습니다. RevenueCat SDK와 광고 이벤트 전송은 제거됩니다. 이전 앱 버전은 업데이트 전까지 이전 SDK를 포함할 수 있습니다.

2026-10-09

영수증 사진의 기기 내 금액·날짜 인식과 저장 전 확인 흐름을 추가하고, Android ML Kit의 기술 진단 처리와 Google(미국) 전송을 고지했습니다. 인식 이미지와 텍스트는 OCR 서버로 전송하지 않습니다. 이용약관 본문은 변경하지 않았습니다.

2026-09-01

출시 성능을 개선하기 위해 EAS Observe의 25% 익명 설치 표본을 고지했습니다. 앱·기기·운영체제·국가·언어·시작·렌더링·메모리·네트워크와 메시지를 제거한 네이티브 충돌 진단을 처리하며, 계정·가계부 식별자, 금액, 메모, 사진, 위치, 라우터 매개변수, 맞춤 이벤트, 자동 JavaScript 오류와 자유 형식 예외 메시지는 제외합니다. 미국 호스팅과 최소 90일 보관 가능성도 명시했습니다.

2026-08-29

Free의 메인 탭 바로 아래 광고와 Pro 구독 조건을 반영했습니다. Google Mobile Ads·UMP 처리, 비개인 맞춤형 요청, Android 광고 ID 차단, iOS ATT 동작, 동의 선택과 RevenueCat 광고 측정을 고지합니다. 금융 내용과 계정 프로필은 광고 요청과 이벤트에 포함하지 않습니다.

2026-08-27

인앱 구독 도입에 따라 RevenueCat, Inc.(미국)를 구독 상태 확인 처리자로 §6에 추가했습니다. 가계부 내용은 전달되지 않습니다. 이전 공개 버전이 없으므로 소급 고지 대상자는 없습니다.

2026-08-26

개인정보처리방침과 이용약관의 최초 문서를 마련했습니다. 서비스 공개 준비 과정에서 운영 정보와 프로덕션 처리 구성을 확인했으며 이전 공개 버전은 없습니다.

한국어 개인정보처리방침이 기준 문서이며 번역문은 이해를 돕기 위해 제공합니다.
