隐私政策

BooKoo 运营方 hyo.dev 仅处理提供和保护服务所必需的信息。

生效日期: 2026-11-04

1. 运营方与联系

运营及隐私联系：hyo.dev · hyo@hyo.dev。可提交权利、安全和隐私请求。

2. 目的与法律依据

用于账户认证、共享账本和邀请、记录/评论/照片同步、可选通知、安全、客服和用户请求。核心处理为履行服务合同所必需，可选功能单独选择。未满14岁不可使用；不收集生日，仅确认年满14岁。

3. 处理的信息

登录提供商标识、提供时经验证的邮箱、显示名、用户名、头像、语言、货币、时区和主题；账本、角色、金额、币种、日期、分类、备注、评论、邀请、收据照片，以及用户自愿附加到记录的地点名称、地址和坐标；推送令牌和必要安全事件。

仅在用户于地点选择器中主动请求时访问当前位置，且可在系统设置中拒绝或撤销。我们不收集后台位置、移动轨迹、通讯录、银行/支付信息、性别、生日或好友列表。应用会屏蔽 Android 广告 ID，也不请求 iOS ATT 权限。为提供免费版广告，Unity LevelPlay/ironSource Ads·Unity Ads 与 UMP 可能自动处理基于 IP 的大致位置、应用互动、诊断、应用/设备标识和广告数据。

在发布版本安装中确定性抽取的25%样本里，EAS Observe 会处理匿名安装标识、应用版本/构建/环境、国家、操作系统、设备型号、语言、启动耗时、帧、内存、设备和网络性能诊断。不会包含账户、账本、记录、金额、备注、照片、地点、查询参数或自定义事件。

收据扫描在设备上从用户选择的照片读取金额和日期，并在应用前要求确认。Android 使用 Google ML Kit，iOS 使用 Apple Vision。识别图像和文本不会发送到 OCR 服务器；只有用户保存记录时，照片才通过现有附件功能上传。

3-1. 可选的按国家使用统计

仅对在隐私设置中同意的账户，将IP估算的国家代码及最近活动时间用于按国家汇总活跃账户。默认关闭，拒绝不影响记账。应用向现有网站托管商Vercel Inc.（美国）发送不含账户标识、认证令牌或Cookie的HTTPS请求，仅接收国家代码。Vercel为估算临时处理IP，其基础设施安全记录适用其自身政策。BooKoo应用、函数及数据库不保存或记录IP地址、城市、坐标或移动轨迹，不请求位置权限。仅保留最近的一个国家代码，并由新记录覆盖。关闭后立即删除国家代码；账户删除适用既有删除政策。VPN或代理可能使估算与实际不同。获取失败、未同意及旧版归为国家未知，不追溯推算过去活动的国家。

4. 共享范围

金额、备注、评论和收据仅对当前账本成员可见。收到邀请的人可按指定角色加入。我们不出售个人信息，也不向广告商发送财务内容或账户资料。Unity LevelPlay/ironSource Ads·Unity Ads 自动处理的有限技术与广告数据见第6节和第9节。

5. 保存与删除

账户数据保存至账户期限及30天恢复期；回收站条目和账本30天；导出文件最多7天；安全/审计记录按目的最多180天或2年；已解决客服记录最多1年。删除账户会移除评论和照片，共享财务记录可能保留并将作者去标识化。法律保留仅限必要范围。

6. 处理商与跨境

Convex Labs LLC 在所选部署地区提供数据库、认证、服务器和文件服务。Resend（美国）处理邮箱、语言和一次性认证邮件，普通方案的邮件与日志保存30天。启用通知时 Expo 与 Apple/Google 处理推送令牌和不含财务内容的最小通知元数据。仅在您使用订阅时，IAPKit（Hyo Dev）会处理应用内部用户标识、商店收据/购买令牌及购买与续订记录，用于判断订阅状态。不会发送账本内容、备注、照片或位置。银行卡信息由 Apple 和 Google 处理，BooKoo 与 IAPKit 均不保存。

Unity Technologies 及其关联公司通过 Unity LevelPlay/ironSource Ads 与 Unity Ads 提供 Free 横幅。为投放、衡量、诊断及防欺诈，可能处理和共享基于 IP 的大致位置、应用/设备/安装标识、广告互动、性能数据、设备语言/型号/屏幕/网络信息及 SDK 披露中列出的购买/使用相关信息。数据经加密传往包括美国、以色列在内的服务商处理地区，并按目的及法律义务所需期限保留。Google LLC（美国）的 UMP 仅负责同意管理；应用不发送 Google Mobile Ads 广告请求。应用屏蔽 Android 广告 ID、不请求 iOS ATT，并限制为非个性化广告。BooKoo 不会主动向广告 SDK 发送账本内容、账户资料或 IAPKit 购买验证凭据。服务商披露的收集范围包括其自身对购买相关信息的处理。不启用 Ad Quality、可选开发者数据共享或自定义广告事件。旧版应用在更新前可能仍包含 AdMob。

Expo Application Services 的 EAS Observe（美国）在发布版本的25%匿名安装样本中处理应用启动与渲染性能，以及设备、操作系统、应用版本、国家、语言和网络诊断。原生崩溃还可能包含数值型异常、信号或终止代码以及符号化代码调用栈。数据托管在美国，并可能至少保留90天。BooKoo 不启用路由器集成、URL 与查询参数、账户或账本标识、自定义事件、用户属性和自动 JavaScript 错误收集，并移除 Android 与 iOS 的自由格式异常消息。

选择 Apple、Google、Kakao 或 Naver 登录时，对方提供标识和获准的最小资料。可停止邮件、通知或社交登录；拒绝 Convex 核心处理将无法提供服务。

Google LLC（美国）的 Android ML Kit 可能通过 HTTPS 发送设备和应用信息、每次安装的标识符、处理时间、图像格式和分辨率、输入输出大小、功能版本、事件类型和错误代码，用于诊断及 API 使用分析。识别图像、文本及结果内容不会发送给 Google。保留和处理遵循 Google 隐私政策；SDK 声明不会与第三方共享这些诊断数据。

7. 用户权利

可请求访问、更正、导出、删除、限制处理或撤回可选选择。可在设置、公开页面或邮件提出。验证账户后处理；若受其他成员权利或法律限制，将说明理由和可行范围。

8. 安全措施

我们使用传输加密、最小权限、环境分离密钥、经认证的照片下载、成员资格复核、限流、计划删除和秘密扫描。财务内容、照片、OTP 与邀请码不会进入推送和普通日志。账本、记录和评论以服务器响应为唯一依据，不会复制到普通设备存储。登录信息和应用锁信息分别保存在独立的安全存储中。

9. 跟踪

Free 版可能在四个主标签正下方、标签栏与设备底部 Safe Area 之间显示一条非个性化 Unity LevelPlay/ironSource Ads·Unity Ads 横幅。该 SDK 可为广告投放、衡量、分析和防欺诈处理基于 IP 的大致位置、应用互动、诊断、应用/设备标识及广告数据。应用会屏蔽 Android 广告 ID，也不请求 iOS ATT 权限。财务内容、备注、收据、地点和账户资料不会进入广告请求。

EAS Observe 的25%安装样本只衡量应用技术性能，不用于广告跟踪或产品行为分析。每次安装的匿名标识不会与其他应用或账户关联，也不会发送页面 URL、查询参数或账本内容。

Android ML Kit 技术诊断独立于广告跟踪和 BooKoo 自定义账本分析事件。SDK 可能在初始化或识别时处理技术指标。收据扫描为可选功能，仍可手动输入记录。

10. 变更与版本

重大变更会提前通知，扩展目的或数据类型时依法另行选择。版本页会保存变更历史。
