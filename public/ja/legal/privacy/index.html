BooKoo

プライバシーポリシー

運営者hyo.devは、サービス提供と安全確保に必要な情報のみを処理します。

施行日: 2026-11-04

1. 運営者・連絡先

運営者およびプライバシー窓口: hyo.dev · hyo@hyo.dev。権利行使、安全、個人情報の問い合わせを受け付けます。

2. 目的と法的根拠

アカウント認証、共有家計簿・招待、記録・コメント・写真の同期、任意通知、セキュリティ、サポート、利用者の依頼のために処理します。中核処理は契約履行に必要で、任意機能は別途選択できます。14歳未満は利用できず、生年月日は収集せず14歳以上の確認を受けます。

3. 処理する情報

プロバイダーID、提供された確認済みメール、表示名、ユーザー名、画像、言語・通貨・タイムゾーン・テーマ。家計簿、役割、金額、通貨、日時、カテゴリ、メモ、コメント、招待、レシート写真、利用者が任意で記録に付けた場所名・住所・座標、プッシュトークン、必須の安全イベント。

現在地は場所選択画面で利用者が要求した場合にのみ使用し、OS設定で拒否・撤回できます。バックグラウンド位置、移動履歴、連絡先、銀行・決済情報、性別、誕生日、友達一覧は収集しません。Android 広告 ID は遮断し、iOS の ATT 権限は要求しません。無料広告のため Unity LevelPlay/ironSource Ads·Unity Ads と UMP が IP に基づくおおよその位置、アプリ操作、診断、アプリ・端末識別子、広告データを自動処理する場合があります。

リリースビルドのインストールから決定論的に選ばれた25%では、EAS Observe が匿名のインストール識別子、アプリのバージョン・ビルド・環境、国、OS・端末モデル・言語、起動時間、フレーム、メモリ、端末・ネットワーク性能の診断を処理します。アカウント、家計簿、記録、金額、メモ、写真、場所、クエリパラメータ、カスタムイベントは含みません。

レシートスキャンは利用者が選んだ写真から端末内で金額と日付を読み取り、適用前に確認を求めます。Android は Google ML Kit、iOS は Apple Vision を使用します。認識用の画像やテキストは OCR サーバーへ送信せず、写真は利用者が記録を保存するときに既存の添付機能でのみアップロードされます。

3-1. 任意の国別利用統計

プライバシー設定で同意したアカウントのみ、IPから推定した国コードと最新の利用時刻を国別アクティブアカウント集計に使用します。初期設定はオフで、拒否しても家計簿を利用できます。既存のWebホストVercel Inc.（米国）に、アカウント識別子・認証トークン・CookieなしでHTTPSリクエストを送り、国コードのみ受け取ります。Vercelは推定のためIPを一時処理し、インフラのセキュリティ記録には同社の方針が適用されます。BooKooのアプリ・関数・データベースはIP、都市、座標、移動履歴を保存・記録せず、位置権限を要求しません。最新の国コード1件のみを接続記録に保持し上書きします。オフにすると即時削除し、アカウント削除にも既存の削除方針を適用します。VPN等で推定が実際と異なる場合があります。取得失敗・未同意・旧版は国不明とし、過去の利用を遡って推定しません。

4. 共有範囲

金額、メモ、コメント、レシートは現在の家計簿メンバーだけに表示されます。招待を受けた人は指定された役割で参加できます。個人情報を販売せず、金融内容やアカウント情報を広告事業者へ送りません。Unity LevelPlay/ironSource Ads·Unity Ads が自動処理する限定的な技術・広告データは第6項と第9項に記載します。

5. 保存と削除

アカウント情報は利用中および削除後30日間の復旧期間まで、ゴミ箱の記録・家計簿は30日、エクスポートは最大7日、安全・監査記録は目的により最大180日または2年、解決済みサポートは最大1年保存します。削除時はコメント・写真を消去し、共有記録は他メンバーのため投稿者を匿名表示にする場合があります。法的保存は必要最小限だけ分離します。

6. 委託・国外移転

Convex Labs LLCは選択した地域でデータベース、認証、サーバー、ファイルを処理します。Resend（米国）はメール、言語、ワンタイム認証メールを処理し、通常プランではメールとログを30日保存します。通知を有効にした場合、ExpoとApple/Googleはトークンと金融内容を含まない最小通知を処理します。IAPKit（Hyo Dev）はサブスクリプションを利用する場合にのみ、アプリ内部の利用者識別子、ストア領収書・購入トークンと購入・更新記録を処理し、契約状態を判定します。家計簿の内容、メモ、写真、位置情報は送信しません。カード情報はAppleとGoogleが処理し、BooKooもIAPKitも保持しません。

Unity Technologies と関連会社は Unity LevelPlay/ironSource Ads・Unity Ads を通じて Free バナーを提供します。広告配信・測定・診断・不正防止のため、IP に基づくおおよその位置、アプリ・端末・インストール識別子、広告操作・性能データ、端末の言語・モデル・画面・ネットワーク情報、および SDK の開示に記載された購入・利用関連情報を処理・共有する場合があります。米国・イスラエル等の事業者の処理地域へ暗号化して送信され、目的と法的義務に必要な期間保管されます。Google LLC（米国）の UMP は同意管理に使用し、Google Mobile Ads の広告リクエストは行いません。Android 広告 ID は遮断し、iOS ATT は要求せず、非パーソナライズ配信に制限します。BooKoo は家計簿内容、アカウント情報、IAPKit の購入検証証明を広告 SDK へ直接送信しません。SDK 自体による購入関連情報の処理は、事業者の収集項目に含まれます。Ad Quality、任意の開発者データ共有、独自広告イベントは使用しません。旧バージョンには更新まで AdMob が残る場合があります。

Expo Application Services の EAS Observe（米国）は、リリースビルドの25%匿名インストール標本で、アプリの起動・描画性能と、端末、OS、アプリバージョン、国、言語、ネットワーク診断を処理します。ネイティブクラッシュでは数値の例外・シグナル・終了コードと記号化されたコードスタックも処理される場合があります。データは米国でホストされ、少なくとも90日保持される場合があります。BooKoo はルーター連携、URL・クエリパラメータ、アカウント・家計簿識別子、カスタムイベント、ユーザー属性、自動 JavaScript エラー収集を無効にし、Android・iOS の自由形式例外メッセージを除去します。

選択したApple、Google、Kakao、NaverはIDと許可された最小プロフィールを提供します。メール、通知、ソーシャルログインは停止できますが、Convexの中核処理を拒否するとサービスを提供できません。

Google LLC（米国）の Android ML Kit は、診断と API 利用分析のため、端末・アプリ情報、インストールごとの識別子、処理時間、画像形式・解像度、入出力サイズ、機能バージョン、イベント種別、エラーコードを HTTPS で送信する場合があります。認識用の画像、テキスト、結果の内容は Google に送信しません。保持と処理には Google のプライバシーポリシーが適用され、SDK はこの診断情報を第三者と共有しないと説明しています。

アクセス、訂正、エクスポート、削除、処理制限、任意選択の撤回を請求できます。設定、公開ページ、メールを利用してください。本人確認後、他のメンバーの権利や法令による制限があれば理由と可能な範囲を説明します。

8. 安全管理

通信暗号化、最小権限、環境別シークレット、認証付き画像配信、メンバー再確認、レート制限、削除ジョブ、シークレット検査を使います。金融内容、写真、OTP、招待コードは通知と通常ログに含めません。台帳、記録、コメントはサーバー応答を唯一の基準とし、通常の端末ストレージへコピーしません。ログイン情報とアプリロック情報は、それぞれ独立した安全なストレージで保護します。

9. 追跡

Free では4つのメインタブの直下、タブバーと端末下部の Safe Area の間に非パーソナライズ Unity LevelPlay/ironSource Ads·Unity Ads バナーが表示される場合があります。SDK は広告配信・測定・不正防止のため、IP に基づくおおよその位置、アプリ操作、診断、アプリ・端末識別子、広告データを処理する場合があります。Android 広告 ID は遮断し、iOS ATT 権限は要求しません。金融内容、メモ、レシート、場所、アカウント情報は広告リクエストに含めません。

EAS Observe の25%インストール標本は技術的なアプリ性能だけを測定し、広告追跡や製品行動分析には使用しません。インストールごとの匿名識別子を別のアプリやアカウントと結び付けず、画面URL、クエリパラメータ、家計簿内容も送信しません。

Android ML Kit の技術診断は、広告追跡や BooKoo の家計簿分析用カスタムイベントとは別です。SDK は初期化や認識時に技術指標を処理する場合があります。スキャンは任意で、手入力も引き続き利用できます。

重要な変更は施行前に告知し、必要な場合は別途選択を受けます。履歴ページに変更履歴を保管します。
