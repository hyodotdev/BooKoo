BooKoo. Private evidence and production exports stay under ignored `.local/`.

monetization, signed-build, or two-client quality gates recorded below.

## Documentation rules

- Record verified facts separately from recommendations and assumptions.
- Link to the authoritative repository document instead of duplicating its
  contract.
- Never paste secrets, private user data, store-console screenshots containing
  personal information, or `.local/` evidence into tracked documentation.
- Product and UI corrections from review sessions also belong in
  `.notes/design/visual-language-2026.md` and reconciliation decisions belong in
  `.notes/design/RECONCILIATION.md`.
